# 齐盛Online

游戏源码与本地玩法位于本目录。正式游戏 https://game.tianhw.top，主站 https://zbqsgz.tianhw.top。继续开发先读 [项目交接](../../docs/HANDOFF.md)，源码、正式发行、验证和目标分别记录。

当前为Preview 0.8.4，香港两站及后端已发布；实际短测与已知限制见项目交接。本轮准备人物倒下／掉落的GPU资源，分离观察与网络同步等待，统一画质并增加电影式制作名单。0.8.3小齐已通过真实生成与独立审核；运行启停由拥有者管理，不因本次发布重设。完整GameAPI拆分与全局寻路预算仍是后续项。

现有账号使用用户名、密码和恢复码，升级保留旧身份记录；拒绝升级者仍可本机游玩、公共阅读和匿名反馈。剧情、漫游和摄影不参与竞技成就；成就来自有效服务端记录，保存统计与公开参榜分别选择。

Node24，在本目录 npm ci、npm run dev；npm run build默认生成匿名演示，正式构建使用npm run build:production并要求独立正式素材，静态预览npm run preview。开发服务只监听本机，Vite显示实际端口。单机玩法不以在线服务可用为启动条件；账号功能需要API。

规则、协议、账号／成就类型、社区和玩家内容维护在同级校园共享模块，游戏使用vendor依赖。模型、碰撞、导航和存档保持各自来源编号；正式托管由校园服务器部署项目负责。
