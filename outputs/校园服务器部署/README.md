# 齐盛Online 发行工具

此目录维护发行政策、资源身份、哈希检查与目标校验。公开仓库不携带真实部署配置、运行数据、SSH密钥或旧发行包。

生产使用本机未跟踪的 deployment-targets.json 作为唯一配置，发布前必须核对 SSH 主机身份；公开示例仅用于配置自己的环境。CI 不持有生产权限。源码默认构建 localhost 演示，实际发行需明确 production，并拒绝演示资源。

常规流程是短验收、打包核验、备份、等待对局结束、切换、公网复检和登记；失败回到兼容版本，不能覆盖数据库或重新打开停用玩法。公开版本与联机协议分别从发行清单和共享规范读取。

完整运维规则见根 docs/operations.md；私密服务器配置与历史验收报告保留本机。
