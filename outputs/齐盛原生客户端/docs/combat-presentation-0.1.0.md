# 原生 0.1.0 战斗表现检查

记录日期：2026-10-18。此记录针对原生表现组件，不代替正式跨端比赛验收；没有修改生产、玩法、协议或地图。

## 本轮已编码

- 互动提示读取正式协议的 kind、action、weapon、available、reason，不再读取不存在的 label / prompt。枪械区分替换和补弹，道具显示实际动作；达到上限时不提供可执行提示，并禁用触屏互动。
- 显示本人权威头盔耐久；低弹提示按当前武器弹匣的20%计算。HUD状态条使用独立薄条样式，避免继承菜单按钮内边距挤出屏幕。
- 消费服务器已经脱敏的 sound 事件。只按量化 bearing 与 near/mid/far 距离档生成临时粗略音源，不读取精确 position，不创建敌方实体、轨迹或坐标历史。被遮挡枪声使用预制的低通合成音。
- 本人权威拾取结果通过 feedback_received 发往 HUD 的短暂文字；未知动作不编造成功结果。
- 枪口、弹迹和爆炸共用网格及材质，进入前绘制准备，分别限制最多24、64和8项活跃效果并复用。烟雾、手雷、头盔和卡牌使用共享材料与网格；不再每次开枪／爆炸新建材质。
- 远端持枪与地面掉枪共用有界模型池；回收前还原原始部件变换，避免装填偏移在复用后累计。恢复／换队时正确更新队色，同队重复显现不再复制材质。
- AWM拉栓柄、R870泵动、M249弹链使用现有真实动作进度；逐发装填按 shellIndex 区分音效阶段。远端在实际具有部件的模型上应用动作，死亡时武器随倒下姿态降低。

## 实际验证

Godot4.7.2、Windows、NVIDIA RTX4070 Laptop／OpenGL Compatibility实际窗口运行 tests/native_combat_presentation_smoke.gd，约2秒，36项通过。覆盖7近景枪、7远景枪、4角色资源准备，真实机械部件动作与归位，协议互动、头盔、粗声音、效果上限、材料身份复用、掉枪池及释放。报告在本机 work/presentation-qa/report.json；1440×900截图为 work/presentation-qa/combat-desktop.png。

截图自审发现菜单主题的 ProgressBar／VBox内边距让装填条落到屏幕外；本轮已改为HUD专用紧凑间距与薄状态条，并重新截图确认。

首轮扩展测试错误假定远端简化LOD必有 bolt-handle，测试异常后已停止自己的窗口，原日志保留 work/presentation-qa/run-far-lod-assumption.log。近景真实部件已验证；远景不存在的细节不伪造。新的复用归位检查使用带真实Node3D部件的原创合成夹具调用实际复用方法。

日志中的Windows根证书仓读取警告仍存在，本轮没有放宽TLS或关闭证书校验；HTTPS账号和联机由跨端验收另行确认。

## 未完成与实际边界

- 这不是自然TDM／FFA完整比赛、真实TCP损伤或安卓真机验收。未据此开放生产连接门禁。
- 材质身份和效果数量有定向证据，尚未用同场景前后帧耗时证明总体性能收益；不宣称全部击倒卡顿已根治。
- 远端简化LOD有些机械细节已被源LOD省略；头盔只显示本人权威状态，公共实体协议未下发他人头盔耐久，不能据此虚构远端装备信息。
- 当前手雷采用轻量几何弹体和爆炸闪光，烟雾为有界球体表现；玩法、伤害、遮挡和拾取仍完全由服务器决定。
- 匿名原生演示仍以菜单和漫游为既有范围，本轮没有引入正式素材或额外搭建演示战斗服务。
