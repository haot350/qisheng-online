# 原生 0.1.0 同步修补记录

维护：2026-10-18。网页版0.9.2已发布；本页仅记录原生内部验收，不构成生产放行。

## 已确定并修复

1. 固定Colyseus Godot 0.18.7将MessagePack扩展转为PackedByteArray。msgpackr对JavaScript undefined使用type0/[0]；delta中省略的roster因此未变成null。旧原生decoder将其拒绝，随后baseSeq连续不匹配，导致大量状态及事件丢失。现仅在这一不允许二进制的可选名单字段识别精确[0]哨兵，保留旧名单；其他二进制、错误序号和错房间仍拒绝。没有修改服务端协议。
2. Rust桥严格f64转换丢失MessagePack整值坐标/输入，恢复检查点时部分轴保留旧值。Root已统一接受有限i64/f64，并完成混合数字实际DLL检查。原94米/57米异常不能全部解释为QA重定位；旧失败证据保留。
3. QA按真正reconciliation_serial采样，避免把上次loading/generation的校正值重复归入下一快照。预测保留120项受限上下文，测试输出只存本机私有报告。
4. 原生结束状态此前每条快照重建结算页面并继续渲染；已改为一次性显示结果、停止3D与本人输入。该项已纳入本次成功TDM与FFA实例验证，结果页只构建一次。
5. 回放时间早于最旧获准动态姿态时，不再用未来姿态补碰撞；清除该次远端碰撞，仍不接收隐藏实体。
