# 原生0.2.0界面整理

状态：已编码并完成实际Godot GPU页面截图与组件信号检查；发布状态以根交接为准。

## 页面与主题

大厅、装备、房间、暂停、账号和资料页统一使用独立战术主题。品牌和功能标题分开，真实校园背景只做背景；文字、按钮、天气选择和装备卡均为原生控件。首页不创建校园世界。局中菜单继续显示原场景，避免用大厅图片替代当前场景。

大厅直接选择团竞、混战或漫游，创建／进入始终保留在底部。1280×720下主要模式、装备和底部行动可见；公开房间、设置、帮助和关于在底部作为次级入口。选装展示六张现有武器图卡与真实参数，固定副武器只占一行。

房间准备固定底部准备、房主开始和离开；未准备、资源准备、等待玩家和等待队员分别说明。天气使用服务器的`room.weather.preset`显示。暂停只突出继续，设置／地图／帮助为紧凑组；离场只保留一个符合当前情境的入口，避免原来两个实际执行同一路径的返回按钮。

## 设置与运行时边界

独立`SettingsPanel`按显示、画质、声音、操作、辅助五页组织，复用现有`action_requested`。选项均映射真实运行时：显示器、窗口模式、窗口尺寸、系统刷新率只读、帧率、垂直同步、兼容／增强渲染、画质与实际3D比例、阴影、抗锯齿、纹理采样、音频通道、灵敏度、键位、开镜与界面大小。

窗口设置保持草稿，只通过`preview-display`调用15秒运行时确认流程；渲染器通过明确重启入口应用。纹理采样称清晰／均衡／柔和，不声称能降低已分配显存。画面倍率与实际3D渲染比例分开显示。增强环境选项只在实际Forward+运行时提供。

普通设置仍立即反馈，存储由运行时合并保存。关闭功能页先回暂停菜单，不发出继续操作。账号页面居中显示登录或基础资料，未上传头像、不把密码放入持久记录。
