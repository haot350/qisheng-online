# 开发范围与后续路线

0.8.0 本轮：用户名密码／恢复码、原身份保留升级、私密找回申诉、预设头像与精选成就、私人竞技统计与公开档案、有效来源成就及撤回重算；后台玩家账号管理、服务状态、房间操作回执及现有聚合数据筛选。具体进度与发布状态由 [HANDOFF](HANDOFF.md) 维护。

后续按玩家实际反馈排序：先补真机账号／键盘与档案流程，再根据运行数据改进房间和加载体验。新竞技统计必须有真实可验证来源；旧记录缺少字段时明确未记录，不推算救起、爆头或维修数量。

暂缓后台SSH控制台、一键数据库恢复、通用手动发奖／改分、自动封禁、账号两步验证、多服调度和全引擎拆分。这些项目需要各自具体收益与验收，不能因“大型后台”名义一次扩展。既有截图附件、原资产和历史证据保留，普通维护不清空生产数据。
