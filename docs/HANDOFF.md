## 既定规则

- 用户名、密码、恢复码账号；新密码6—128个字符。旧身份升级保留 player_id、成绩和反馈，拒绝升级仍可本机游玩与匿名反馈。
- 详细统计、近期比赛及反馈仅本人可见；公开档案、私人战绩同步和参榜分别控制。成就只能来自有效竞技记录，撤回来源后重新计算。
- 单机菜单暂停世界，联机个人菜单仅停止本人操作；关闭功能页先回菜单，明确继续才恢复。演示环境与正式资源、身份和比赛分离。
- 默认演示构建，正式构建必须显式选择 production；生产发行拒绝 demo。真实校园、原素材、历史发行与持久数据不能因开源或回滚删除。
- 共享同步后检查各锁文件的 Linux optional 记录；后端或锁变化做一次干净 Linux 安装。常规必要验收目标十分钟以内，不重复完整故事、长局或压力测试。
- 前端锁同时包含两组WASM依赖：Sharp需要根级 `@emnapi/runtime` 1.11.3；Rolldown WASM绑定精确需要1.10.0的core/runtime嵌套记录。保留不同版本的合法共存；仅Windows安装通过不能证明Linux干净clone通过。
