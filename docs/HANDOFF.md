# 齐盛Online 开发交接

最后维护：2026-10-31。当前源码为 Preview 0.10.0；两站、API及三个实时进程已发布，公网复检通过。实际线上状态以正式入口的发行清单为准。此前0.9.7上线后已回退，废弃的0.9.7/0.9.8地图候选不作为当前接入基线。

## 源码与运行

- `outputs/校园逃生游戏`：浏览器游戏、模式流程、输入、地图流送与客户端预测。
- `outputs/校园交互网站/site`：校园网站和三维浏览。
- `outputs/校园排行榜服务`：玩家账号、成绩、反馈、运营与管理后台。
- `outputs/校园联机服务`：服务器裁判、房间、重连和输入处理。
- `outputs/校园共享模块`：规则、协议、社区页面及地图客户端。消费者使用vendor包，更新时保留跨平台optional锁记录。
- `outputs/校园服务器部署`：公开的部署边界示例和纯校验模块；生产配置独立管理。

需要Node 24。推荐 `node scripts/dev-demo.mjs --install` 启动本地匿名演示；默认游戏地址为 http://127.0.0.1:5180。手动只构建游戏时，先在共享模块执行 `npm ci`，再在游戏执行 `npm ci` 和 `npm run build`。演示使用独立地图身份和本机服务，不连接正式房间或参榜。主站在其site目录单独安装和启动。

正式校园、人物、声音和品牌美术不在公开仓库。源码中的地点目录、validated点位及map-layout均为匿名示例；正式资产需要按独立交付清单接收，不能据演示构建判断整校通行或画质。

## 本轮改动

0.10.0收敛位置驱动LOD、必要结构交接、共享图片解码、GPU实例准备和缓存后台写入；补充楼栋/唯一楼层身份与导航。NPC修补瞄准姿态、攻击席位公平、有限搜索和跨层避让；坦克将前进限速与履带差速分开。枪伤、攻击人数、计分与联机技术栈保持原规则。

地图索引保持schema1，物理读取支持旧容器与QSC3；协议为campus-mp-0.9.4。正式轻量地图使用web-r01-campus-1目录，新旧成绩范围分开，旧凭证继续结算。账号数据库仍为schema6。

## 验证与待办

公开匿名游戏已完成完整类型检查和默认演示构建。正式候选已做受影响行为、真实胶囊路线和一次浏览器出生点转向短测；用户要求缩减测试，没有重复完整剧情、容量、全部楼层截图或双浏览器完整对局。

手机60帧仍是优化目标，Safari、安卓真机、真实多指与移动网络尚无本轮结果。首次击倒长帧和公网回拉仍需按具体场景保留证据，不能从本次短样本宣称全部根治。

继续开发优先复用会话令牌、资源租约、输入生命周期和现有服务器裁判。每次记录应区分已实现、已验证和已发布；历史发行事实见各版本记录。
