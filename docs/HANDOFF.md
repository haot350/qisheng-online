# 齐盛Online 开发交接

## 当前源码候选：Preview 0.13.0

网页、API、共享模块及受影响联机源码为0.13.0，安卓0.4.0／versionCode 5；协议继续campus-mp-0.9.4。此处是源码接收状态，正式发布与设备测试以最终发行记录为准。

本轮包括分步准备、自动任务指引、匿名地图底图、安卓独立布局、博客与评论、后台按钮开关，以及人物素材策略和账号测试资格。博客公开页面由API的blog-public.ts服务端渲染，游戏及主站提供入口，不依赖游戏引擎加载。

数据库schema8从schema7增量迁移，加入博客、媒体引用、评论、社区限制及测试资格。现有账号、头像、成绩及存档保留。兼容回退保留新库与人物访问控制，避免重新开放旧公共素材。

人物外观保留同一玩法身份和裁判口径。公开源码不包含真人RGB、正式虚构人物美术、正式命中掩码或校园地图；匿名演示使用公开适配器。生产人物目录需独立提供，后台策略与每账号资格由API判断，浏览器不能提交外观权限。小齐根据可信资格调整公开知识中的NPC显示名，生成及独立审核共用本轮知识，玩家原文保持不变。

公开演示的battle-map.json与map-layout.json由scripts/build-demo-battle-map.mjs生成；两份文件具有anonymous-demo-1身份，不能替代正式校园通行或性能验收。公开源码的vendor包可由共享源码重建，四个消费者锁文件保留跨平台optional记录。

本地安装与演示见DEMO.md。正式素材、签名、生产配置、测试代码、数据库、日志与发行回执独立保存。

## 源码与运行

安卓独立模块为`outputs/齐盛安卓客户端`，与退役Godot工程分别维护。公开Android Manifest映射到原创占位图标；正式资源、签名、APK及本机工具路径继续排除。浏览器匿名演示和Linux构建入口保持原样。

- `outputs/校园逃生游戏`：浏览器游戏、模式流程、输入、地图流送与客户端预测。
- `outputs/校园交互网站/site`：校园网站和三维浏览。
- `outputs/校园排行榜服务`：玩家账号、成绩、反馈、运营与管理后台。
- `outputs/校园联机服务`：服务器裁判、房间、重连和输入处理。
- `outputs/校园共享模块`：规则、协议、社区页面及地图客户端。消费者使用vendor包，更新时保留跨平台optional锁记录。
- `outputs/校园服务器部署`：公开的部署边界示例和纯校验模块；生产配置独立管理。

需要Node 24。推荐 `node scripts/dev-demo.mjs --install` 启动本地匿名演示；默认游戏地址为 http://127.0.0.1:5180。手动只构建游戏时，先在共享模块执行 `npm ci`，再在游戏执行 `npm ci` 和 `npm run build`。演示使用独立地图身份和本机服务，不连接正式房间或参榜。主站在其site目录单独安装和启动。

正式校园、人物、声音和品牌美术不在公开仓库。源码中的地点目录、validated点位及map-layout均为匿名示例；正式资产需要按独立交付清单接收，不能据演示构建判断整校通行或画质。

## 本轮改动

0.11.0将B方向水彩界面接入菜单、准备、大厅、房间、设置和社区页面，桌面、手机网页与安卓使用各自适合的导航。安卓0.2.0与网页同批发行，完整资源随包并绑定构建清单，沿用既有升级签名。原生方向、对局归属与前台运行分别管理；开局前有界等待横屏，系统返回复用真实页面路径。0.10.2的准备交接、玻璃及加载机制继续保留。人物透明轮廓生成器沿用既有规则，正式掩码和照片不包含在本仓库。

地图索引支持schema1与schema2，schema2校验压缩内容及解码内容的两份哈希；物理读取支持旧容器与QSC3；协议为campus-mp-0.9.4。正式轻量地图使用web-r01-campus-1目录，新旧成绩范围分开，旧凭证继续结算。账号数据库仍为schema6。

本轮公开源码包含B方向的实际组件与样式；其余UI概念和正式视觉素材仍独立管理。完整Noto字体OFL和实际依赖许可随发行提供。
