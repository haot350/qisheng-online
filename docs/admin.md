# 管理后台

入口为 https://game.tianhw.top/admin，使用独立管理员账号；玩家账号无法登录后台。owner 管理管理员权限、审计和私密找回申诉。普通管理员按领域授权：feedback、publish、ranking、players、player-accounts、rooms、stats、operations。新增 player-accounts 不自动授予原管理员；“账号与权限”管理后台管理员，“玩家账号”管理游戏玩家。

原有工作台、反馈、议题、版本、玩法通知、成绩审核、玩家、房间、访问故障、管理员权限与审计继续使用。0.8.0 增加玩家账号详情与筛选、负责人找回申诉、服务状态；房间补操作回执，访问与故障补版本／玩法／设备筛选和趋势图。

玩家账号可查看升级状态、竞技统计和成就来源，调整参榜限制、停用账号、隐藏公开档案、撤销会话或按来源重算。操作需原因与修订校验并写入具名审计；不改变比赛分数、不手动授予成就。隐藏档案不删除私人记录，停用会撤销登录会话。

玩家的战绩同步开关只控制单人突围／大飞的本局记录；关闭不抹去已有历史，重算不补回关闭期间的单人记录。联机私人战绩与成就始终记录，公开参榜仍由各自发布选择及资格决定。

负责人处理申诉时先核验独立归属证据，再明确填写玩家ID。默认可以拒绝证据不足的申诉；同名或短编号不能自动认领。批准生成24小时一次性重置凭证，仅数据库哈希及提交者私密回执查询可用，后台响应与审计不输出原始凭证。处理状态和修订防止重复批准覆盖。

服务状态为只读：显示实际目标、当前发行、三工作进程健康响应、房间心跳与已有性能数据。房间模拟更新时间不是完整周期或公网延迟；内存是工作进程RSS，不能按房间求和。健康接口与历史部署复检分别标注时间，不把旧复检当作现在的健康保证。

房间指令提交只代表排队；回执显示等待、工作进程接收处理或超过60秒未确认。超时指令仍可能稍后执行，避免立即重复提交。关闭房间会中断比赛，部署维护只停止新开局，玩法开关与部署维护独立。

版本说明与部署证据分开；编辑公开说明不会使版本上线。统计复用脱敏日汇总，不收集IP或完整UA；“估计会话”“页面访问”“在线人数”含义不同。反馈原文、截图、诊断和内部备注保持私密，公开议题只发布审核后的摘要。
