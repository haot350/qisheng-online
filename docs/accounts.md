# 账号与个人头像

账号界面、客户端和共享类型位于 `outputs/校园共享模块/src/community` 与 `src/accounts.ts`；账号服务位于 `outputs/校园排行榜服务/src`，管理员页面位于其 `admin` 目录。个人头像与枪战角色使用独立类型，更新头像不会改变战斗角色。

## 本轮接口

下列路径由API注册为 `/v1/...`，正式站点通过同源 `/api/v1/...` 使用；安卓动态网络路由保持同一前缀。

| 方法与路径 | 用途 |
|---|---|
| `POST /v1/accounts/avatar` | 当前账号上传已裁剪图片，提交 `dataUrl` 与 `expectedUpdatedAt`，返回更新后的身份与账号 |
| `DELETE /v1/accounts/avatar` | 删除上传图片，可同时传预设 `avatar`，校验 `expectedUpdatedAt` |
| `GET /v1/accounts/avatar` | Bearer会话读取本人图片，查询参数为 `size=96\|512` 和当前 `revision` |
| `GET /v1/players/:id/avatar` | 读取当前公开头像，每次检查账号及公开状态 |
| `POST /v1/players/appearances` | 批量查询最多50个 `playerIds` 的公开外观；私密与未知身份统一回退姓名头像 |
| `GET /v1/accounts/matches` | 本人战绩分页，可传 `mode`、`cursor`、`limit`；每页最多20局 |

图片描述 `avatarImage` 为可选字段，原预设 `avatar` 保留。旧客户端修改预设不会删除上传图片，显式删除或新界面切回预设才清理图片。房间在成员变化或可见页定时刷新时读取外观，图片不进入战斗快照。

## 图片处理与隐私

支持静态JPEG、PNG和WebP，输入上限5MiB及2000万像素。前端检查图片头后提供拖动、缩放与预览，服务端重新校验、旋正及编码为512和96像素WebP，两张合计不超过192KiB。原图和元数据不保存。

每账号每小时最多20次提交，头像总存储预算256MiB；头像与反馈图片共用两路处理预算。异步处理完成后再次验证会话、账号和档案修订，再以事务保存当前图片。失败或取消选图保留原头像。上传完成前，页面保留真实处理中状态。

公开头像随公开档案开关生效；关闭后本人可查看，其他玩家看到姓名头像。图片响应使用 `no-store`，私有图片使用Bearer请求为Blob，令牌不进入图片URL。客户端缓存有容量、时限及身份失效边界，组件释放ObjectURL。

## 战绩与设备

战绩分页采用提交时间、来源和ID的稳定游标。记录保留公开、私人、复核及无效状态；单人有效成绩可通过既有接口公开或撤回，合作及对战继续使用团队规则。累计统计读取全部有效来源，缺失历史字段显示暂无记录，最佳成绩按难度、车型及规则区分。

会话只记录粗粒度平台及浏览器、登录与最近活动时间；最近活动最多每五分钟写入一次。旧会话没有新增信息时如实显示，现有撤销设备和全部退出继续使用。

## 数据迁移与回退

schema7新增 `account_avatars` 与 `session_details`，保留原 `sessions` 的三列结构。头像按账号保存一份，替换或注销时清理，随SQLite备份一并保存。上线前在临时数据库验证迁移、级联清理和恢复。

已有schema7写入后，回退使用接受schema7的兼容API并保留当前数据库。只接受schema6的旧API不可直接启动新库；静态版本回退与数据库恢复分别处理。

## 公开演示

公开仓库不含用户上传图片、数据库或正式人物与校园素材。匿名演示使用临时账号及原创资源。头像客户端边界检查位于共享包的 `tests/accounts-avatar-v012.test.mjs`；API权限、格式和迁移检查位于排行榜服务测试目录。正式素材构建与匿名演示保持独立地图身份。
