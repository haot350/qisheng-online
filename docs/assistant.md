# 小齐助手维护

小齐只提供公开玩法、操作、账号使用和反馈帮助。游戏菜单与个人菜单进入独立页面，不加载模型推理到浏览器，不增加战斗悬浮窗。

## 服务与配置

API 的 assistant、assistant-config、assistant-service、assistant-upstream 模块负责来源验证、额度、私密配置、两次调用和响应。共享 assistant 入口定义公共类型，connection-summary 仅接受有界数字白名单。管理员 assistant 权限独立授权，接口、模型、密钥及测试只允许拥有者操作。

正式服务默认读取数据库目录下的 `private/assistant-private.json`，即持久 `data/private` 中的私密文件；目录权限0700、文件0600，与静态网站和发行目录分开。该位置使用现有 systemd 可写 data 路径，不需要放宽系统配置目录权限。运行配置中的 `assistantConfigFile` 可显式覆盖，由运维保证目标可写和私密。没有配置时默认关闭。接口接受标准 `/v1` 基础地址（自动补全）或完整 `/v1/chat/completions` 请求地址，其他路径不自动拼接。后台先保存接口、模型和密钥，再测试生成与审核，最后启用。密钥不回显；更换主机需重新填写，模型变化使旧测试失效。不要把该文件、上游回执或聊天内容加入源码和发行。

每日数据库备份在该文件存在时生成同名 `.sqlite.assistant.json` 私密配套文件，权限0600，随数据库保留最近14份；没有配置文件时正常备份。数据库恢复默认不覆盖小齐配置，确需恢复时由拥有者选择配套文件、在维护状态下单独恢复并校正权限，避免无意恢复旧密钥或旧启用状态。

## 回答边界

服务端仅检索共享公开玩家说明，不检索源码、交接、日志、后台或私人数据。生成和审核使用同轮冻结的相同提供方与模型、独立上下文；审核失败不返回候选。提示词没有秘密，不能靠其保密承担安全责任。同模型审核仍可能共同误判，模型只提出受限菜单计划，没有战斗、私人资料或后台操作权限。

问题最多1500字符，最近六轮有界上下文；一次最多60秒。访客默认每日30轮、账号300轮、同时每人一轮及全站三轮，默认全站2000万Token／北京时间自然日。后台连接测试最多每分钟30次；触发时显示剩余等待秒数。两次调用及管理员测试计入额度；预算保守预留，缺失用量不乐观退还。公开游客接口不能保证完全阻止脚本滥用，不能把Origin检查等同不可伪造身份。

API保存脱敏用量与限额，不长期保存聊天正文。短期内存仅用于取消与重试去重；本机对话可清除，切换账号清理。反馈草稿经玩家修改并确认后走原反馈接口，截图、诊断不自动交给模型；反馈正文继续私密。

## 菜单安排与回答风格

生成先回应当前问题，普通答疑不罗列能力限制；独立审核核对候选，不因玩家原话越界、口语或抱怨直接拒绝安全帮助。两段固定提示与工具范围由服务端追加，拥有者只能编辑风格和补充审核偏好。自然语言必须封装在严格JSON内，审核仍只返回approved。

普通玩法、难度、装备与允许设置的已审核安排自动执行；建房/入房的整份计划先确认。卡片逐项显示实际开始、完成与失败，资源就绪后由玩家点击卡内进入。开始、准备、离场与战斗控制不作为模型工具。页面/账号变化和取消停止计划，历史不重放副作用，旧卡不能接管新安排。

## 接续与验证

采用可替换上游适配器作拒绝、超时、预算、取消和权限短测。真实密钥未配置时，只能报告适配器与界面验证通过，不能声称真实提供方可用。联网服务的开关和实际启用状态单独登记。

0.9.2：公共状态增加独立noticeRevision。知情确认按本机身份与该修订保存，不依赖模型/额度等运营配置revision；账号切换后读取对应确认。已确认时示例直接提问，首次先展示告知再继续原问题。服务端独立审核、菜单工具能力与房间确认不变。
