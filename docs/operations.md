# 发行与运维

公开仓库提供源码、演示环境和通用发行政策，不包含生产主机、配置、账号或密钥。生产操作读取本机不跟踪的 'outputs/校园服务器部署/deployment-targets.json'，执行前必须核对目标身份。首次配置使用脱敏示例；不要把示例地址作为线上服务器。

默认开发只监听localhost。游戏和主站的 'npm run build' 是匿名演示；实际发行使用 'npm run build:production'，完整地图、碰撞、导航和视线身份一起校验。演示和正式资源不能混装，正式打包拒绝demo。

正常流程：构建与短验收 → 核验发行哈希 → 备份 → 停止新开局并等待已有比赛结束 → 切换 → 公网复检 → 登记部署。运营开关与公告保留，回滚不覆盖数据库、照片、存档、附件或新账号。公开版本、协议和规则各自取规范来源，不互相推算。

账号数据库schema6；跨schema回滚必须有验证过的兼容程序，不能恢复旧库丢失新增账号。仅改静态页面时不应重启联机。服务器故障与网络问题先区分线路、模拟、发送积压和画面校正；日志不得输出恢复码、Bearer凭据、密码或完整个人材料。

私密部署记录和历史数据核验保留在本机旧交付目录及 'work/private-project-state'，不上传到GitHub。CI仅安装、构建和短测，不持有生产发布权限。
