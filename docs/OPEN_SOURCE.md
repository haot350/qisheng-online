# 公开源码范围

仓库：`haot350/qisheng-online`；原创代码与演示素材的版权主体为 OpenQS，许可证为根目录 MIT。第三方软件继续遵循各自许可证，依赖版本由各模块锁文件固定，`docs/THIRD_PARTY.md` 说明依赖与署名来源。

网页六个当前模块保持在 `outputs/` 下：校园逃生游戏、校园交互网站、校园排行榜服务、校园联机服务、校园共享模块、校园服务器部署。历史发行、备份、建模交付和私有素材在本机保留原位置与编号，公开仓库仅收录白名单中当前源文件；公开工作不会将整个工作区或历史目录上传。

公开内容包括程序源码、必要配置模板、包 manifest／锁文件、短定向检查、原创 demo SVG／小场地和由当前共享源码重建的特定 `vendor/qisheng-shared-<version>.tgz`。共享 tarball 仅含当前源码、构建脚本与可重建 JS/CSS，消费者不依赖私有开发目录链接。

不公开真实人脸及其衍生贴图、真实校园地图／模型／照片、品牌位图、模式封面、正式成就插图、剧情媒体、正式部署目标／私有配置、账号凭据／会话／恢复码、数据库、日志、备份、历史交付、`node_modules`、生成的 `dist` 或其他二进制资产。MIT 不授予未包含或第三方私有素材的使用权。

人物 PNG 提取的命中轮廓与部位校准也属于未公开素材，不以 TS 数据形式上传。公开模块仅提供抽象正方形校准和空人物轮廓；正式游戏与实时编译必须显式选择 production 并提供独立授权的 `校园逃生游戏/private-data/` 校准文件，缺少时失败，不以公开占位数据代替正式命中判定。

执行 `node scripts/public-source.mjs --list` 查看精确白名单，`--check` 检查路径和 vendor 内容，`--export <empty-directory>` 生成一次性审查副本。该工具不初始化 Git、不提交、不推送；发布由维护者在审查后执行。`.gitignore` 使用默认拒绝及显式源码路径，最终纳入内容仍以白名单审查为准。

默认构建为 [本地演示](DEMO.md)。生产资源具有自己的来源标识和哈希，demo 使用独立身份；生产发行守卫拒绝 demo 构建，公开 clone 不能借演示资产发布正式校园。

独立原生模块 `outputs/齐盛原生客户端` 公开Godot/Rust自有源码、固定工具链、构建脚本、主题、匿名演示规则与第三方许可。正式 `content/production/` 和 `content/combat/`、桥二进制、安装包、签名、内部测试记录均排除。当前匿名原生演示为菜单与漫游，不能将缺少正式战斗素材的演示称为已通过正式跨端对战。Windows账号会话的API来源隔离与DPAPI、损坏清理、原子替换已经定向验证；实际原生发行仍须通过独立安装包和跨端门槛。安卓公开仍需Keystore与真机验证。

原生0.2的正式`content/branding/`背景、`content/audio/`录音与其清单、GPU截图和崩溃转储同样不公开。`ENGINE-DECISION.md`、`UI-0.2.0.md`仅提供脱敏的技术取舍和界面行为说明。生成目录继续默认排除，只明确允许可重建的三种天气常量与对应Godot UID；工具校验其字段、数值及纯数据格式，不把其他生成的地图或人物数据放行。

每轮可以运行`node scripts/audit-public-source.mjs --version 0.9.4`准备审查。它只读取白名单源文件，逐项计算SHA256，并检查四份共享归档内部、代码依赖闭包、签名配置、凭据特征和正式素材排除，结果只记为PREPARED。源码冻结、旧版已跟踪vendor归档从Git索引移出并复核后，运行同命令加`--final`生成当前版本审查；`--final --verify`确认白名单和所有字节未在审查后改变。报告位于本机版本证据目录，不纳入公开仓库；工具不会自动暂存、提交或推送，也不能代替人工复查。
